# Security policy

Do not report a vulnerability with sensitive details in a public issue. Contact
RiskDataScience GmbH through the contact information in the
[imprint](https://riskdatascience.net/impressum/).

The package processes local data and performs no telemetry or automatic network
downloads. Institutions remain responsible for filesystem permissions,
secrets, access controls, dependency patching and operational isolation. Only
the latest released version is supported with security fixes.
